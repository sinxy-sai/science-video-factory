# Information Grid / Information Theory

This episode uses a cool laboratory palette derived from information diagrams: midnight blue background, electric mint for encoded signals, pale blue labels, and thin grid lines. Use binary cells, branching diagrams, probability marks, and measured data-like motion. Avoid poster typography, vermilion accents, and generic title-card layouts.

## Tokens

- Background: `#07111F`
- Primary text: `#E7F0FF`
- Signal accent: `#48D7C4`
- Muted labels: `#6F89A8`
- Grid structure: `#17304A`
- Display: geometric sans or system sans
- Metadata: monospace
