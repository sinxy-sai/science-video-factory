# Browser Renderer Fixture

This fixture verifies the browser route only. It uses HTML/CSS for layout, SVG for the diagram, JavaScript and GSAP for deterministic motion, HyperFrames for inspection and rendering, and Remotion as the downstream compositor.

## Colors

- `#0d1320`: canvas
- `#f4f7fb`: primary text
- `#6de0c8`: process bar
- `#ffb86b`: emphasis
