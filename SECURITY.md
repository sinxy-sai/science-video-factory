# Security policy

## Supported versions

Only the latest commit on the default branch and the latest published release
receive security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private vulnerability reporting feature for this repository, or contact the
maintainer through the private contact configured on the repository. Include
the affected version, reproduction steps, and any suggested mitigation.

You should receive an acknowledgement within seven days. We will coordinate a
fix and disclosure timeline with the reporter.
